# User Manual - Hardy Cross Moment Distribution

Welcome to the Hardy Cross Moment Distribution GUI! This tool calculates the member-end moments, shear forces, and support reactions for continuous beams.

## Starting the Application
1. Open a terminal or command prompt.
2. Navigate to the project directory.
3. Run the following command:
   ```bash
   python -m src.mdm.main
   ```
4. Look for the console output indicating the server has started (e.g., `Open http://127.0.0.1:8000 in your browser.`).
5. Open the provided link in your web browser.

## Using the Interface

### 1. Beam Configuration
The "Beam Input" section allows you to configure the general properties of the continuous beam:
- **Number of supports:** The total number of supports (minimum of 2). Changing this value automatically updates the "Spans" section.
- **Maximum cycles:** The maximum number of moment distribution cycles to perform.
- **Tolerance:** The convergence tolerance. The calculation stops once the unbalanced moment at every joint falls below this value.
- **Exterior supports fixed:** Check this box if the first and last supports are fixed (encastre). If unchecked, they are treated as pinned/roller supports.

### 2. Span Definition
For each span, you must provide its properties:
- **Length L (m):** The length of the span in meters.
- **UDL w (kN/m):** The Uniformly Distributed Load on the span.
- **Point loads:** Enter point loads in the format `P@a`, where `P` is the load magnitude (kN) and `a` is the distance from the left support of the span (m). Multiple point loads can be separated by semicolons (e.g., `12@2; 8@4.5`).

### 3. Calculation & Output
Click the **Calculate** button to perform the analysis. The results are displayed in several tabs:
- **Distribution Factors:** Shows the stiffness calculation and distribution factors for each member at every joint.
- **Fixed-End Moment Calculations:** Details the fixed-end moments (FEM) generated by the applied loads before distribution.
- **Moment Distribution:** The step-by-step Hardy Cross iterative distribution table.
- **Reactions:** Shows detailed step-by-step span and support reaction force calculations, including Equilibrium Checks.
- **SFD / BMD:** Visualizes the Shear Force Diagram and Bending Moment Diagram, along with detailed calculations for values along each span, maximum values, and points of zero shear.
- **Final Support Moments:** Summarizes the final moments at each support.
