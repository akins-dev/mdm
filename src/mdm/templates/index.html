Beam Input

Leave unchecked if exterior supports are pins/rollers (not strictly fixed).
Why? (click to expand)
In practice, the ends of continuous beams typically rest on columns or walls that allow rotation — these are modelled as pins or rollers, not fixed supports. Only check this box if the beam ends are specifically designed as fully rigid connections (e.g. monolithic connections into shear walls or deep foundations) where rotation is physically restrained.

Spans

UDLs use w@start-end, where start and end are distances from the left support. For a full-span UDL, simply enter the value (e.g. 15). Separate multiple UDLs with semicolons.

Point loads use P@a, where a is the distance from the left support. Separate multiple point loads with semicolons.
